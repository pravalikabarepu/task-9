# Superstore Sales & Profit Analysis 📊

## Project Overview

This project analyzes Superstore sales and profit data using Microsoft Excel. 
An interactive dashboard was created to identify sales trends, profitable regions, top-performing products, and category performance.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning

## Dashboard KPIs

- Total Sales: $2,296,919.49
- Total Profit: $286,409.08
- Total Orders: 9,993
- Total Quantity: 9,993

## Dashboard Analysis

The dashboard includes:

- Monthly Sales Trend
- Top 10 Products by Sales
- Sales & Profit by Category
- Profit by Region
- Sales by Region
- Region Slicer
- Category Slicer
- Year Slicer

## Key Insights

- Sales show variation across months with an overall upward trend toward the later periods.
- The Technology category generates strong sales performance.
- Regional performance differs, providing opportunities to identify high-performing and underperforming markets.
- A small number of products contribute significantly to overall sales.
- The interactive slicers allow users to analyze performance by region, category, and year.

## Project Structure

- `superstore.xlsx` – Excel workbook containing the cleaned data, PivotTables, charts, and interactive dashboard.
- `Dashboard` – Final interactive dashboard.
- `Clean-data` – Cleaned Superstore dataset.

## Objective

The objective of this project is to demonstrate practical skills in:

- Data cleaning
- Data analysis
- Excel PivotTables
- Dashboard development
- Data visualization
- Business insights

## Conclusion

The Superstore dashboard provides an interactive view of sales and profitability, helping users understand product, category, regional, and time-based performance.
